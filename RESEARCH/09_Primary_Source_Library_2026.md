## Secretary-General / UN reporting

### A/79/88 — 2024 Secretary-General report on LAWS
https://documents.un.org/doc/undoc/gen/n24/154/32/pdf/n2415432.pdf

This is a critical source because it reproduces state submissions, including Serbia, India, Japan, Israel, Russia, Germany, France, Sri Lanka, Sweden, Switzerland, UK, USA and many others.

When using a state's submission, cite the state's own section inside this document rather than treating the consolidated SG narrative as the state's exact words.

## Source discipline

When a secondary monitor gives a state position:
1. use it to locate the underlying primary statement;
2. quote/paraphrase the state itself;
3. record the date;
4. preserve older positions as historical evidence rather than treating them as current.
