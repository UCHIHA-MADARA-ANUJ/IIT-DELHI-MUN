
# 15 — Regulatory Design Variables Matrix

This is the agenda's master policy-design matrix. It is intentionally neutral: it records the choices the committee will have to make.

| Variable | Option A | Option B | Option C | Key question |
|---|---|---|---|---|
| Scope | narrow LAWS | broader autonomous weapons | broader autonomy + adjacent AI | Which capabilities are actually regulated? |
| Characterization | platform-based | function-based | capability-based | Does the rule survive technological change? |
| Critical functions | select + engage | identify + select + engage | wider targeting cycle | Where does autonomy become legally sensitive? |
| Legal form | political declaration | CCW protocol | standalone treaty | What forum can deliver durable rules? |
| Prohibition test | IHL-incompatibility | unpredictability/lack of control | direct autonomous human-targeting | Which category is clearly unacceptable? |
| Regulation test | use/context | system design | both | Can a legal weapon become unlawful through use context? |
| Human role | direct control | indirect/contextual control | mixed standard | What must humans actually do? |
| Intervention | mandatory where feasible | mandatory in specified contexts | pre-use constraints only | What if circumstances change? |
| Operating limits | target | target + geography | target + geography + time + scale | How bounded must autonomy be? |
| Testing | pre-deployment | pre + post-deployment | continuous lifecycle | When does assurance expire? |
| Legal review | Article 36 where applicable | national equivalent | harmonized international minimum | How do non-AP I States participate? |
| Material modifications | every change | material changes | only changes affecting critical functions | When does re-review trigger? |
| Accountability | command chain | lifecycle duties | command + lifecycle duties | Who owns which responsibility? |
| Traceability | records retained nationally | confidential international review | public aggregate reporting | How much transparency is feasible? |
| Incident reporting | voluntary | mandatory serious incidents | mandatory periodic reporting | What evidence must States share? |
| Verification | national | peer review | international inspection/audit | How intrusive can verification be? |
| Procurement | national practice | supplier obligations | treaty procurement standards | Can contractors be part of compliance? |
| Transfers | national export controls | treaty controls | treaty + ATT coordination | How prevent diversion/proliferation? |
| Non-State actors | domestic law | transfer controls | transfer + counter-proliferation cooperation | How do you stop diversion? |
| Capacity-building | voluntary | technical assistance | dedicated fund/programme | How can all States implement? |
| Review mechanism | periodic conference | expert body | conference + expert body | How does the regime adapt? |
| Civilian AI boundary | strict separation | interface controls | broader dual-use governance | How avoid regulating ordinary civilian AI? |

## The five questions that compress the entire agenda

1. **What is covered?**
2. **What is prohibited?**
3. **What is allowed under strict conditions?**
4. **What must States do throughout the lifecycle?**
5. **How can compliance be demonstrated without exposing sensitive military information?**

## Why this matrix matters for Brazil

Brazilian strategy should later be built by locating:
- non-negotiable preferences;
- acceptable compromise positions;
- provisions that attract different regional groups;
- provisions where Brazil can draft bridging language.

But that analysis should occur only after the 86-state country matrix is fully normalized.
